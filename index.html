How to Use Git Bridge

Get started with Git Bridge in just a few simple steps

1

Getting Started

Download and extract Git Bridge, then run the application. On first launch, you'll see the setup wizard to configure your Git credentials.

  • Enter your Git username and email
  • Add GitHub Personal Access Token (optional)
  • Choose your preferred theme

Setup Wizard Screenshot

Repository Management Screenshot

2

Repository Management

Create new repositories, open existing ones, or clone from remote sources. The sidebar provides quick access to all repository operations.

  • New: Create a new Git repository
  • Open: Open an existing repository
  • Clone: Clone from GitHub/GitLab
3

Managing Changes

The Status tab shows all your file changes. Right-click files to stage them, view diffs, or perform other operations.

  • Modified: Files with changes
  • Staged: Files ready for commit
  • Untracked: New files not in Git

File Changes Management Screenshot

Commit and Sync Screenshot

4

Committing & Syncing

Once you've staged your changes, commit them with a descriptive message. Then push to share your changes or pull to get updates.

  • Commit: Save changes with message
  • Push: Upload changes to remote
  • Pull: Download remote changes
5

Advanced Features

Explore the History tab for commit visualization, Files tab for repository browsing, and the command console for advanced Git operations.

  • History: Visual commit graph
  • Files: Repository file browser
  • Console: Direct Git commands
